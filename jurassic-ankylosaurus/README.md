# 侏罗纪公园：绿甲龙群龙大战 (Jurassic Ankylosaurus)

单文件原生 HTML5 Canvas 恐龙冒险小游戏，零外部依赖，双击 `index.html` 即可在浏览器全屏畅玩。

## 玩法特色

- **主角绿甲龙**：身披坚硬绿色背甲，移动灵活，带有重型尾锤。
- **远古植物系统**：
  - 🌿 **无毒远古蕨草**：`+1 分`
  - 🍎 **黄金龙果**：`+3 分`
  - 🍄 **剧毒紫蘑菇**：`-2 分`（误食扣分但不会死亡）
- **草丛保护色隐身**：躲进地图上的大型绿色草丛（`🌿草丛隐身区`）后，甲龙绿色的身体与草丛融为一体，所有食肉恐龙会瞬间丢失目标（头顶冒出 `❓找不到`）并转身离开。
- **360° 旋风尾锤反击**：按 `空格键` / `J` / `鼠标右键` 或点击屏幕右下角按钮，挥动重型尾锤震飞周围食肉恐龙并造成伤害（命中带血条的恐龙 3 次即可将其彻底击倒，`+5 分`）。
- **丰富恐龙生态**：
  - 🦖 **霸王龙 (T-Rex)**：体型巨大，锁定冲刺
  - 🐊 **巨型棘龙 (Spinosaurus)**：背帆巨兽，高威胁猎手
  - 🦎 **迅猛龙 (Velociraptor)**：成群巡逻，移动极快
  - 🧪 **双冠毒龙 (Dilophosaurus)**：张开颈伞远程喷射毒液球
  - 🦅 **天空翼龙 (Pterosaur)**：无视地形高空俯冲掠食
  - 🦕 **友军三角龙 (Triceratops)**：草食盟友，主动撞飞食肉恐龙并掉落黄金龙果
- **4 档难度与通关条件**：支持简单、普通、困难、地狱模式，吃满目标分数或击倒指定数量食肉恐龙即可通关获胜。
