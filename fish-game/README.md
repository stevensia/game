# 大鱼吃小鱼

页面最上方显示：**李慕思设计的游戏**。

适合 7 岁小朋友的海底小游戏，无倒计时、无广告、无外部资源请求。

## 打开游戏

双击本文件夹的 `index.html`，用 Edge、Chrome、Firefox 或 Safari 打开即可。无需安装软件或联网；分享时请把整个 `fish-game` 文件夹一起复制。

## 玩法

- 点击“开始探险”，用方向键或 `W A S D` 控制黄色黄貂鱼，也可以按住页面下方的方向按钮。黄貂鱼是 stingray（魟鱼）造型，有金黄色的扁平身体、宽大的翼状胸鳍和细长尾巴。
- 蓝灰色印鱼是黄貂鱼的好伙伴。它头顶有吸盘，会自动跟在玩家身边，不会被吃掉，也不参与计分。
- 海里同时有更多可吃的小鱼。普通小鱼和粉金色鲷鱼增加 1 条，海底橙色螃蟹增加 2 条，带“沙丁鱼群 +10”标记的鱼群一次增加 10 条；在 10、30、60 条时长大。
- 比你大的鱼必须绕开；一旦碰到，黄貂鱼会被大鱼吃掉，本局结束，可以立即再试。
- 吃到 110 条即可完成挑战，成为“黄貂鱼之王”。
- 空格、`P` 或暂停按钮用于暂停和继续。离开浏览器窗口或切换标签页会自动暂停；返回后手动继续。
- 音效默认关闭，点击“音效：关”可开启轻柔的吃鱼和成长提示音。
- “重新开始”会从 0 条小鱼开始新一局。

## 开发

`index.html` 为页面，`style.css` 为样式，`game.js` 包含游戏逻辑与 Canvas 绘图。全部为原生 HTML / CSS / JavaScript，无第三方依赖。

已安装 Node.js 时，在此文件夹运行逻辑测试：

```powershell
node --test game.test.js
```

如需要本地 HTTP 预览，已安装 Python 时可运行：

```powershell
python -m http.server 8765 --bind 127.0.0.1 --directory "C:\Users\listeven\fish-game"
```

再访问 `http://127.0.0.1:8765`。本地服务不是游戏运行的必要条件。
