# Mini Games Collection (儿童网页小游戏合集)

本仓库包含两个纯原生 HTML5 / CSS / JavaScript 开发的网页小游戏，无任何第三方依赖或外部请求，双击对应目录下的 `index.html` 即可在浏览器中直接运行。

## 目录结构

| 目录 | 游戏名称 | 简介 | 启动方式 |
| :--- | :--- | :--- | :--- |
| [`./fish-game/`](./fish-game/) | **《大鱼吃小鱼》（李慕思设计的游戏）** | 控制黄色黄貂鱼（带蓝灰色印鱼伙伴）在海底吃小鱼、鲷鱼、螃蟹与沙丁鱼群不断长大，躲避大鱼与鲨鱼，吃满 110 条通关。 | 打开 `fish-game/index.html` |
| [`./jurassic-ankylosaurus/`](./jurassic-ankylosaurus/) | **《侏罗纪公园：绿甲龙群龙大战》** | 控制绿色甲龙吃无毒远古蕨草与黄金果、避开毒蘑菇，利用绿色草丛保护色隐身，挥动 360° 旋风尾锤反击霸王龙、棘龙、迅猛龙、双冠毒龙与翼龙，并有友军三角龙助战。 | 打开 `jurassic-ankylosaurus/index.html` |
